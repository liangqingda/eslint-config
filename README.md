# @liangqingda/eslint-config

一套可复用的 ESLint / Prettier 配置，适用于 JavaScript、TypeScript 和 React 项目；
另外自带一个零依赖的 SCSS 排版与类名检查脚本 `liangqingda-check-scss`。

仓库里对外公开的入口文件统一收拢在 [`exports/`](/Users/lqd/projects/eslint-config/exports) 目录中，便于区分包入口与内部实现。
